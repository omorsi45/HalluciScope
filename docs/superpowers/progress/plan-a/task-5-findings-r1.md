# Task 5 open findings (round 1), verbatim from the review

1. Concurrent migrate calls on a fresh database crash (backend/db/migrate.py:72-73). The schema_migrations create table if not exists and initial verify run outside the advisory lock; Postgres IF NOT EXISTS is not concurrency-safe. Two migrate() calls via asyncio.gather on fresh databases failed 15/15 with UniqueViolation pg_type_typname_nsp_index. Fix: do the bootstrap inside its own async with conn.transaction(): taking pg_advisory_xact_lock(%s) first, then _CREATE_TABLE and _verify(migrations, await _applied(conn)); add a gather test. pending() at :94 has the same race.
2. Fixture leaks a database on partial setup failure (tests/pg_fixtures.py:75-76). await create_database(name) is before the try:, and create_database creates the db then reconnects for extensions (:58-60); if the extension step fails, drop_database never runs. Fix: move await create_database(name) inside the try (drop ... if exists makes finally safe).
3. dev-postgres.sh start breaks on repo paths with a space (scripts/dev-postgres.sh:33). pg_ctl passes -o through /bin/sh -c, so -k $ROOT/.local word-splits. Fix: -o "-p $PGPORT -k '$ROOT/.local'".
